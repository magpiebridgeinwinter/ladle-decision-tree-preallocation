- 重要说明：两图时间条完全相同，只表示计划窗口未改变，不表示 AQ 与 AR 的资源分配相同。
- 边界：当前源数据没有取包点、落包点、任务持续时间或 PLC 连续坐标，因此图中天车不是实测运动轨迹。
