# LLM 局部重调度验证报告

**日期：** 2026-08-14  
**分支：** `feature-1.0`  
**范围：** 真实 PLAN/CRANE 离线回放、滑窗预配验证、局部扰动三路对比与离线测试。

## 结论

局部重调度能力已完成离线验证。系统保持“决策树优先、LLM 仅在非紧急且决策树失败时兜底”的生产语义；本次真实数据回放中决策树能够完成所有纳入炉次的分配，未出现规则违反。由于 10 个 Demo 扰动场景中的决策树均成功，LLM 未被调用，相关 LLM 成功率按约定记为 N/A，而非 0%。

## 实现范围

- 180 分钟滑窗预配与 `unallocated`、`preallocated`、`locked` 生命周期。
- 锁定炉次分配保护和可追溯审计记录。
- 行车不可用、钢包不可用、设施不可用、计划偏差四类单一扰动。
- 以 `最早开浇时刻 - 事件时刻 - 90 秒` 为准的 LLM 时间预算。
- 决策树优先、预算耗尽后 Frozen + 人工复核、LLM ReAct 受约束兜底。
- Frozen、决策树、LLM 三路指标及 LLM 指标 N/A 语义。
