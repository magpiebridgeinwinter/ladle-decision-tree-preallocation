硬约束校验清单（决策树与 LLM 共用同一套）

钢包状态：非 offline/maintenance/scrapped
等级匹配：grade_matches(required, actual)
行车载重：current_load + ladle_weight ≤ max_load
运行区间：limit_0 ≤ ladle_position ≤ limit_1
时间窗：expected_arrival ≤ window_end
安全间距：|position_a − position_b| ≥ safe_distance
氩气：LF/LATS 路线检查 argon_north/south
包龄：age_seconds ≤ max_age_seconds

决策树永远先执行

决策树是生产主路径（毫秒级）。只要它能生成合规方案，系统不会调用 LLM。LLM 只在决策树搞不定的困难场景中顶上。

LLM 不是放宽约束

LLM 输出必须通过 validate_output 同一套硬约束终检。缺失炉次、重复钢包、超时、JSON 错误或违反任何约束均被拒绝并进入人工复核。

90 秒内转人工

预算 ≤ 0 时禁止 LLM，返回 Frozen + human_review_required。Frozen 不改写锁定炉次分配，受影响炉次原地硬扛等待人工介入。
