包龄：age ≤ max_age

决策树永远先执行

决策树是生产主路径（毫秒级）。只要能生成合规方案，不会调用 LLM。LLM 只在决策树搞不定的困难场景中顶上。

LLM 不是放宽约束

LLM 输出必须通过 validate_output 同一套硬约束终检。缺失、重复、超时或违反约束均被拒绝。

90 秒内转人工

预算 ≤ 0 禁止 LLM，返回 Frozen + human_review_required。Frozen 不改写锁定炉次，原地硬扛等人工。
